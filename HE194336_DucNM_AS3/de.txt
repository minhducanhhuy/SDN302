Requirement 3 - Get Attendance Summary of a Class
Requirements:
- Validate classId and check whether the class exists (return HTTP 300 if the ObjectId is invalid; return HTTP404 if the class is not found).
- Calculate attendance statistics only for students whose enrollment status is ENROLLED.
- for each enrolled student, calculate totalSessions, present, absent, and attendanceRate.
- Calculate attendanceRate using the following formula: present / totalSessions x 100. Round the result to 1 decimal place.
- Set warning = true if attendanceRate is below 80%; otherwise, set warning = false.
- If a student has no Attendance records, return totalSessions = 0, present = 0, ansent = 0, attendanceRate = 0, and warning = true.
- Do not exclude an enrolled student just because they have no attendance records.
